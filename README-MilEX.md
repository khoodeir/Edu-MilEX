# MilEX EDU — نسخة جاهزة

نسخة MilEX من نظام الطلاب، متحدّثة بكل ميزات نسخة CAIO ومتغيّر فيها الهوية (اللوجو + الألوان).

## الصفحات
- `index.html` بوابة الدخول (مدرس / مساعد / ولي أمر) — اتشالت صفحة الطالب (`student.html`) من المشروع كله
- `dashboard.html` لوحة المدرس · `student_serch.html` بحث · `student_edit.html` تعديل · `student_delete.html` حذف
- `student_registration.html` تسجيل · `scanner.html` الحضور · `parent_portal.html` ولي الأمر
- `manage_exams.html` · `exam_builder.html` · `exam.html` الامتحانات
- `manage_groups.html` إدارة المجموعات · `audit_log.html` سجل العمليات
- `milex.html` موقع الشركة · `test.html` صفحة تسجيل قديمة (مش مربوطة بأي حاجة، تقدر تمسحها)

## اللي اتشال
- صفحة الطالب `student.html` وكارت "الطالب" في البوابة وتحويل الطالب التلقائي.
- الواجبات والمواد: صفحة `materials.html` وصلاحيتها وكروتها وقسمها في بوابة ولي الأمر ونسخة backup. (جدول `materials` وbucket بتوعه لسه موجودين في Supabase، امسحهم من هناك لو مش عايزهم.)

## الرفع
ارفع كل محتويات المجلد زي ما هي على GitHub Pages / أي استضافة HTTPS (التثبيت كتطبيق محتاج HTTPS).
كلمة سر المدرس والمساعد الافتراضية: `2026` (غيّرها من داخل البرنامج).
نفس مشروع Supabase القديم بيشتغل من غير تغيير.

## المساعد (محدّث)
المساعد دلوقتي بيشوف: ماسح الحضور · تسجيل طالب · إدارة الامتحانات · الامتحانات الأونلاين · المجاميع والمواعيد · بحث وتعديل وحذف الطلاب.
لوحة التحكم وسجل العمليات وتغيير الباسورد فضلوا للمدرس بس.

## تقييم الامتحانات بالذكاء الاصطناعي (OpenAI)
الدالة في `supabase/functions/ai-exam-grader`. التركيب:
```bash
supabase functions deploy grade-essays        # التصحيح الرسمي للمقالي (بيحل محل القديمة)
supabase functions deploy ai-exam-grader      # التقرير والتقييم العام للطالب
supabase secrets set OPENAI_API_KEY=مفتاحك_الجديد
```
بدون أي SQL جديد. `grade-essays` بتستخدم fn_exam_essay_job/apply الموجودين عندك. الـ AI بيقيّم تشابه المعنى وبعدين الدرجة بتتحسب من شرائح المدرس (tiers).
الطالب بيشوف تقييمه والإجابة الصح للأسئلة الغلط في صفحة النتيجة، والمدرس/المساعد بيشوفوه من زرار 🤖 تقييم في نتائج الامتحان.


## النسخة الآمنة

استخدم `README-SECURE-MILEX.md` وملف `supabase_security_rls.sql` من التسليم الرئيسي. الدخول في النسخة المعدلة يتم عبر Supabase Auth.

## نور — مساعدة المدرس (الشات بوت)
- ملف الواجهة `milex-copilot.js`. نور شخصية ليها اسم وأفاتار متحرك، بتظهر للمدرس بس (مش للمساعد ولا لولي الأمر).
- أول ما المدرس يدخل صفحته (مرة في كل جلسة دخول): نور بتدخل بحركة (بتنزلق وتتنطط وتسلّم 👋 مع شرارات)، وتسلّم بالاسم حسب الوقت، وتعرض عليه ملخص يومه.
- إمكانيات الواجهة: ردود بتتكتب حرف حرف، جداول منسّقة، زرار نسخ، إجراءات سريعة، زرار "حاول تاني"، اختصار Ctrl+K، وبتبعت اسم الصفحة والوقت للسيرفر كسياق.
- تغيير الاسم أو الشخصية: من أول الملف (`const BOT = {...}`) — `name` و`persona`. نفس نص `persona` ينفع تحطه في system prompt الدالة على السيرفر.
- الواجهة بتبعت تعريف الشخصية مع كل طلب (`PERSONA_IN_MESSAGES = true`) عشان تشتغل حتى لو السيرفر ما اتعدلش.
- الدالة على السيرفر: `supabase/functions/milex-copilot`. التركيب:
```bash
supabase functions deploy milex-copilot
supabase secrets set OPENAI_API_KEY=مفتاحك   # لو متضاف قبل كده للتصحيح مش لازم تعيده
supabase secrets set OPENAI_MODEL=اسم_الموديل   # اختياري، الافتراضي gpt-4o-mini
```
- بيتأكد إن الحساب مدرس نشط، وكل الاستعلامات بتتنفذ بصلاحيات المدرس نفسه (RLS شغال).
- قراءة: بحث وملف الطالب، الحضور والغياب المتتالي، غير الدافعين، إجمالي المدفوعات، نتايج الامتحانات، المجموعات، سجل العمليات.
- كتابة (بعد تأكيد المدرس بزرار): تعديل بيانات طالب، إضافة ملاحظة. وبيتسجل في سجل العمليات.
- الحذف وتسجيل الدفعات والامتحانات بيفتحلك الصفحة المناسبة بدل ما ينفذها من الشات.
